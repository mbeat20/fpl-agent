# FastAPI backend, unified with ingestion in one Python project

Supersedes ADR-0006. The backend (API + reasoning + tools) moves from Next.js to FastAPI. Since ingestion (Understat scraping, FPL API, Grok/X calls) is already Python, backend and ingestion now live in one Python project instead of two runtimes bridged only by the Postgres schema — sharing the same Pydantic models for Layer 2's "messy text → structured fact" extraction, the same Anthropic SDK setup, and the same database access layer. Ingestion still runs on-demand (ADR-0002), invoked as a script/CLI command within this project rather than a fully separate process. This also keeps the codebase in the same language the reference MCP SDK is built in, ahead of Layer 4 tools eventually becoming an MCP server. The frontend stays a separate project (ADR-0009) and talks to this backend over HTTP.
