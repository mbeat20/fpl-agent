# v1 logs outcomes against Creator Stances and Recommendations, even though nothing reads them yet

Extends ADR-0001 (manual trust tiers for v1, computed accuracy deferred to v2). Even though v1 doesn't compute or use creator accuracy scores, it still records the outcome of each Creator Stance and Recommendation once known — next gameweek's price movement, points scored, whether a captain pick paid off — sourced from data already being pulled from the FPL API each week. This is a "start the clock" decision: v2's Transfer/Captain Accuracy scoring needs historical track record to compute from, and that history can only be built going forward from whenever logging starts. Writing it now costs little (the outcome data already exists in the weekly ingestion) and means v2 isn't stuck waiting months for its first usable dataset.
